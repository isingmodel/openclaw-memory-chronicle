# OpenClaw books

## Canonical memory history

[OpenClaw Memory](openclaw-memory-ko/README.md) is the OpenClaw repository's canonical long-form account of the memory harness: its history, architecture at the stated cutoff, evolution motives, evidence, and evaluation roadmap. The book is written in Korean and keeps technical identifiers and primary-source links in their original form.

Update the book first when its historical or architectural account changes. Public product documentation remains the operational reference for individual features and configuration surfaces, and should be aligned when the same change affects those contracts.
